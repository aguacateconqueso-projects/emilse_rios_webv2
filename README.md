# Contrabajo en la Ciudad

Sitio web de **Emilse Ríos** — contrabajista y docente. Newsletter *Contrabajo en la Ciudad*.

Bilingüe (ES / EN). Construido con [Astro](https://astro.build).

## Desarrollo

```bash
npm install
npm run dev      # servidor local en http://localhost:4321
npm run build    # build de producción en ./dist
npm run preview  # sirve el build
```

## Cómo trabajamos

Cada cambio entra por su propio Pull Request a `main`, por mínimo que sea.
El estado del proyecto y lo que queda pendiente vive en [`progreso.md`](./progreso.md).
